# OFX 어댑터와 렌더 코어를 분리한다

Resolve의 플러그인 수명주기와 호스트 메모리를 다루는 OFX 어댑터 뒤에, 렌더 요청과 주입된 `RenderBackend`만 받는 렌더 코어를 둡니다. `RenderBackend`가 저장소, 임시 버퍼, 패스 실행, 완료 시점을 캡슐화합니다. CPU 백엔드는 동기 완료하고 Metal 백엔드는 호스트가 제공한 명령 큐에 작업을 제출합니다. 효과 수학은 큐와 버퍼 형식을 알지 않으며 두 백엔드가 같은 처리 명세를 구현합니다. 이 구조로 Resolve 밖 CPU 검증과 M3 Pro의 Metal 성능을 함께 확보합니다.
