# 카메라 로그 변환은 Resolve가 담당

플러그인은 카메라별 Log 변환을 내장하지 않습니다. DaVinci Resolve가 카메라 Log를 프로젝트 작업 색공간으로 변환하고, 사용자는 각 효과의 `Working Mode`를 `DWG / Intermediate`, `DWG / Linear`, `Rec.709 / Gamma 2.4` 중 실제 입력과 일치시킵니다. 플러그인은 이 명시값으로 광학 효과를 내부 선형광으로 변환해 처리한 뒤 원래 인코딩으로 되돌립니다. Film Grain은 내부 로그 노출·농도 영역에서 입자를 합성합니다. 호스트가 색공간 메타데이터를 항상 제공한다고 가정하거나 입력을 자동 추정하지 않습니다. 이를 통해 카메라 지원 목록과 이중 변환을 피하면서도 장면 기준 밝기 처리를 명확히 보장합니다.
