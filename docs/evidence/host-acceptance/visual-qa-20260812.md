## Red-to-green host defects

### Strong White Mist edge polarity

- Red: Generic White 2 could produce dark/inverted outlines on a non-negative camera-original scene.
- Root cause: signed veil extrapolation above 1.0, unconstrained positive-branch composition, and a downsampled retention reference in the UHD pyramid.
- Green: signed interpolation is capped at 1.0, excess strength is positive-only scatter, and exact/pyramid paths use full-resolution positive source retention.
- Automated CPU, Metal exact, forced UHD pyramid, M4, build, and strict signing gates pass.

### Lens diagnostics displaying the source

- Red: the Inspector showed non-Final views, but Resolve displayed the source frame.
- Real-host trace: correct view ordinals reached both CPU and Metal `render-enter`, but no invocation reached `render-exit`.
- Root cause: the Lens-only external `Matte` clip was described as required even though the product contract says it is optional. A disconnected matte therefore failed before backend submission and Resolve displayed its source fallback.
- Fix: `Matte` now declares `kOfxImageClipPropOptional=1`; the host probe locks this descriptor contract.
- Green: the same single Wetsuit clip produced black-background `Ghost Paths`, isolated `Elements Only`, and a thresholded `Lens Source Matte`. Runtime trace showed paired `render-enter`/`render-exit`, `submission=Enqueued`, `error=None`.
